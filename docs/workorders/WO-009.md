# WO-009: チャンクタイプ NE 事前分布 θ(ハードゲートの確率化)

担当: impl-core(opus。セッション上限時は codex 代替) / ブランチ: fix/WO-009
対象: tg/include/snpylm.h, tg/src/snpylm.cc, tg/src/sne.cc, tests/test_snpylm_roundtrip.cc
前提: WO-008(clattice 整理 + OOB 修正)マージ後の dev から分岐

## 背景

snpylm は `NE_ADMISSIBLE[chunktype2::n]`(snpylm.cc:77-110)の bool 表で、チャンクタイプごとに
NE クラスを許可/遮断している(_slice の ne_ok、snpylm.cc:878-879)。これを「タイプ毎の NE の
出やすさ」を表す学習可能な事前分布 θ に置き換える(ユーザー要望 2026-07-18)。
設計は codex 相談済み(階層事前・センタリング・EB 循環回避を反映)。

## モデル(司令塔確定 — 変更禁止。矛盾発見時は停止して報告)

各 NE span を 1 個のカテゴリ観測 ct ∈ [0, chunktype2::n) とみなす 2 階層 Dirichlet:

- 共有層: q̂(ct) = (n(ct) + β_ct) / (n(·) + Σβ)。β は固定の非対称事前 — 現行 bool 表を転化:
  true 型 β=THETA_HI(既定 30)、false 型 β=THETA_LO(既定 0.1)。実測 NE 密度は prior に
  入れない(EB 循環回避)。
- クラス層: θ̂_k(ct) = (n_k(ct) + κ·q̂(ct)) / (n_k(·) + κ)。κ 既定 30。plug-in 階層。
- スコア: NE emission(k≥1)に **log θ̂_k(ct) − log q_cand(ct)** を加算(センタリング必須)。
  q_cand = 学習開始時に全文の clattice2 候補型を数えた固定背景分布(add-one 平滑、serialize)。
- deficiency: O 側は払わない補助因子(ψ/l1 bypass と同じ論法)。コメント明記。

## 実装

1. カウント: `_theta_sh`(vector<int>, chunktype2::n)+ `_theta_k`(フラット (K+1)×chunktype2::n、
   `_psi`/`_psii` パターン踏襲)。**着席は `_seat` の ch.k>=1 分岐**(_necnt/_nelen と同じ場所)で
   add/remove 対称に両層 ±1。_resize での拡張も ψ と同様に。
2. スコア加算: `_emit_lp` で k≥1 の全 emission に加算。**τ の外**(_tau 倍の対象にしない)。
   ch.type が範囲外(<0 or >=chunktype2::n)の場合は加算スキップ。
3. ゲート置換(_slice, 878-879 付近):
   - 既定: ne_ok を撤廃(全型 NE 候補)、θ が確率的に抑制。
   - `--hard_type_admission`: 旧 bool ゲートを復活(比較・安全弁)。
   - 既存 `--no_type_admission`: θ もハードゲートも切る(完全中立)に再定義。
4. q_cand 測定: mcmc()(sne.cc)で学習開始前に corpus の各文に clattice2 を張り候補 chunk の
   type を集計 → set_qcand(vector<double>) で渡す(add-one 平滑・正規化はモデル側)。
   ※ 全文格子は重い場合、コスト次第で「corpus の全 chunk 候補型」の近似でよいか司令塔に確認。
5. CLI: `--theta_hi F --theta_lo F --theta_kappa F`(既定 30 / 0.1 / 30)、
   `--hard_type_admission`(flag)。usage 更新。
6. serialize: 末尾追記 + 新負マジック(WO-007 の SNPYLM_GEN_MAGIC=-770007 方式、別値 -770009)。
   保存: ct 数、K、theta_hi/lo/kappa、q_cand、_theta_sh、_theta_k、有効 flag。
   旧モデル(マジックなし/EOF): θ 無効 + ハードゲート fallback で load(cerr 警告 1 行)。
7. roundtrip テスト拡張: 全 add→全 remove 後に _theta_sh/_theta_k 全ゼロ。

## 受け入れ基準

1. OpenMP 有効/無効ビルド(既存以外の警告なし)、ctest 全通過(θ ゼロ検証込み)。
2. スライス経路生存 assert 発火なし(tiny run)。
3. tiny run(300 文, n=3, -k5, 2ep, --init_random)完走・log P 有限。
   `--hard_type_admission` でも完走(旧経路の数値回帰なし: 完走+有限スコアで可)。
4. save→load→parse 一致。旧モデル(sne_v13.model)load で警告+fallback 動作。
5. NPBNLP_SNPYLM_STATS=1 の stats() に θ の上位型ダンプを追加(ψ ダンプと同様、クラス毎
   top-2 型と質量)。

## 禁止事項

- ρ/λ/ψ/H_k/l1 bypass/generic backoff への変更。
- clattice2 の候補列挙の変更(格子構築は不変)。
- 設計と実コードの矛盾を発見したら改変せず停止して報告。
