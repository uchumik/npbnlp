## 2. clattice2 の wt[k-1] OOB 修正(既知バグ)

clattice.cc:353 付近:

```cpp
for (auto k = j; k >= 0 && j-k < chsize[t]; --k) {
    ...
    t = chunktype2::transition(t, wt[k-1], wt[k]);  // k==0 で wt[-1] を読む UD
    if (t < 0) break;
}
```

k==0 のとき `wt[-1]` は範囲外読み(ゴミ値が transition の prev に渡り、遷移表添字も範囲外になり得る)。**k==0 では transition を呼ばない**(k>0 ガードで囲む等、周辺コードを読んで文頭の意図に合う最小修正を選ぶ)。格子候補が非決定ゴミ依存から決定的になるため、候補集合が僅かに変わり得るのは想定内。
